# Отчёт: голосовой ассистент для задач, напоминаний и встреч

Дата: 2026-10-19. Размер запуска: standard. Все 12 задач выполнены, каждая прошла проверку QA и security.

## Что сделано

Веб-прототип по ТЗ (`docs/source/tz.txt`). Пользователь говорит (Web Speech API, ru-RU) или пишет в свободной форме на русском. Ассистент создаёт задачи, напоминания и встречи, показывает планы на период, ищет старые записи и отвечает текстом и голосом (озвучку можно выключить). Работает без платных ключей: запросы разбирает собственный NLU на правилах с Luxon (Europe/Moscow). Поиск по основам слов (Snowball), с синонимами, видовыми парами глаголов и нечётким совпадением. Хранение: SQLite/libSQL локально, Turso на хостинге. У «Демо» загружена история из CSV: 1000 записей, тип определяется по тексту.

Сверх обязательного: изменение, удаление с подтверждением, отметка «выполнено», контекст диалога («перенеси её на завтра»), конфликты встреч с вопросом «Всё равно поставить?», выбор из нескольких подходящих записей, уточняющие вопросы, несколько пользователей по имени без пароля.

## Решения

- ADR-001: Next.js 16 + TypeScript, Drizzle + libSQL/Turso, NLU на правилах, Vercel
- ADR-002: слои голос → HTTP → NLU → диалог → сервисы/поиск → хранение
- ADR-003: состояние диалога — серверный конечный автомат
- ADR-004: дата МСК + момент времени UTC
- ADR-005: ранжирование поиска
- ADR-006: импорт CSV, тип по тексту, без дублей
- ADR-007: необязательный LLM-разбор не делаем

Открытых эскалаций нет.

## Известные ограничения и что можно доделать

- AC-21 на хостинге (Turso после «засыпания») не проверялся: нет доступа к аккаунтам.
- Лимит запросов хранится в памяти процесса и доверяет `X-Forwarded-For`. На Vercel этого достаточно, при другом хостинге — нет. Нет CSP и защиты от CSRF при входе по имени. Это принятые риски открытой ссылки без пароля. Подробности в `.crew/reviews/*-security.md`.
- `APP_NOW` и `RATE_LIMIT_DISABLED` игнорируются только при `VERCEL_ENV=production`. На preview-деплоях и при своём хостинге их нельзя задавать.
- Интерфейс: на телефоне шапка занимает три строки, и диалог начинается ниже, чем мог бы. Переключатель пользователя можно сделать компактнее.
- Понимание запросов построено на правилах. Необычные формулировки вне протестированных могут не распознаваться. Следующий шаг — необязательный LLM-разбор как запасной вариант, а также повторяющиеся задачи и интеграция с календарём (см. README, «Что улучшить»).

## Как запустить

```bash
npm run setup   # зависимости, миграции, загрузка CSV для «Демо»
npm run dev     # http://localhost:3000
```

Тесты: `npm run check`, `npm run test:e2e`; при первом запуске нужен `npx playwright install chromium`. Голосовой ввод работает в Chrome и Edge, в других браузерах остаётся текстовый ввод.
