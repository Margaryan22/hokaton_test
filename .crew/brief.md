# Brief: Голосовой ассистент для задач, напоминаний и встреч (прототип)

Источники: ТЗ `docs/source/tz.txt`, интервью `.crew/interview.md`, история `docs/source/voice_assistant_events.csv`.

## Goal
Тестовое задание: прототип веб-ассистента, который голосом или текстом на русском языке (свободные формулировки) создаёт задачи, напоминания и встречи, показывает планы на период и находит старые записи, отвечая голосом и текстом. Акцент на логике: понимание запроса, корректная работа с данными, уточняющие вопросы. Оценивают проверяющие по открытой ссылке по критериям ТЗ: работоспособность, качество понимания, архитектура, работа с данными, качество кода, UX.

## Users and roles
- **Пользователь** — единственная роль. Несколько пользователей, у каждого свои записи и свой диалог. Входа с паролем нет: открытая ссылка, пользователь выбирается/создаётся по имени (простой переключатель). Чужие записи не видны и не находятся поиском.
- Проверяющий — тот же пользователь; админ-роли нет.

## Data
- **Пользователь** — имя (уникальное), дата создания.
- **Запись** — тип (задача / встреча / напоминание), название/текст, дата и время (могут отсутствовать у задачи без срока), дата создания, статус (не выполнено / выполнено), владелец.
- **История диалога** — реплики пользователя и ассистента, для контекста («перенеси её на завтра») и показа на экране.
- Данные сохраняются между запросами и перезапусками. Часовой пояс везде Europe/Moscow (UTC+3).
- **Начальная история**: `voice_assistant_events.csv` (id,date,time,text; 1000 строк, 2024-01-07..2027-12-31) загружается как готовая история для поиска. Тип определяется по тексту (без учёта регистра): текст начинается с «встреч», «созвон» или «демо», либо содержит «планёрк» — встреча; текст начинается с «напомн» — напоминание; иначе — задача (так «Отправить итоги встречи Иваном» и «Подготовиться к встрече с Партнёром» — задачи, а «Встреча с Иваном по CRM» — встреча). Статус всех импортированных — «не выполнено». Принадлежит демо-пользователю «Демо» (см. Assumptions).

## User stories
- **US-1** Как пользователь, я хочу сказать или написать задачу/напоминание в свободной форме, чтобы она сохранилась с датой и временем.
- **US-2** Как пользователь, я хочу создать встречу, чтобы она попала в расписание, а при пересечении получить предупреждение.
- **US-3** Как пользователь, я хочу спросить, что у меня запланировано на период, чтобы получить понятный список.
- **US-4** Как пользователь, я хочу найти старую запись по смыслу, не помня точных слов.
- **US-5** Как пользователь, я хочу, чтобы при нехватке данных ассистент задал уточняющий вопрос.
- **US-6** Как пользователь, я хочу изменять, удалять и отмечать выполненными записи, в том числе со ссылкой на предыдущую реплику.
- **US-7** Как пользователь, я хочу говорить в микрофон и слышать ответ, а также видеть диалог и список записей.
- **US-8** Как пользователь, я хочу, чтобы у каждого из нас были отдельные данные.
- **US-9** Как проверяющий, я хочу открыть прототип по ссылке и запустить его по README без платных ключей.

## Acceptance criteria
Условие для примеров: текущий момент — понедельник 2026-10-19 10:00 МСК (приложение допускает фиксацию «сейчас» для тестов, например параметром конфигурации). Пользователь — «Анна», если не указано иное. Фразы можно вводить текстом.

- **AC-01** (US-1) Фраза «Напомни мне завтра в 10 утра позвонить Ивану» создаёт запись типа «напоминание», текст содержит «позвонить Ивану», время 2026-10-20 10:00; ассистент отвечает подтверждением с датой и временем (например, «Напомню 20 октября в 10:00: позвонить Ивану»), запись появляется в списке на экране.
- **AC-02** (US-1) Фраза «В пятницу нужно отправить отчет» создаёт задачу «отправить отчет» на 2026-10-23; время не указано — запись без времени, вопрос о времени не задаётся.
- **AC-03** (US-1) Фраза «Поставь задачу купить билеты до конца недели» создаёт задачу «купить билеты» со сроком 2026-10-25 (воскресенье), без времени; подтверждение называет срок.
- **AC-04** (US-2) Фраза «Добавь встречу с командой завтра в 15:00» создаёт встречу «встреча с командой», 2026-10-20 15:00; а «В четверг в 11 у меня встреча с дизайнером» — встречу «встреча с дизайнером», 2026-10-22 11:00. Оба ответа подтверждают действие.
- **AC-05** (US-5) На «Поставь встречу с Иваном завтра» ассистент отвечает «На какое время поставить встречу?» и ничего не сохраняет; после ответа «в 14:30» создаётся встреча с Иваном 2026-10-20 14:30 и приходит подтверждение.
- **AC-06** (US-1) Относительные даты и время: «Напомни через два часа выпить воды» → напоминание «выпить воды» на 2026-10-19 12:00; «Поставь задачу позвонить в банк послезавтра» → задача на 2026-10-21; «Что у меня на следующей неделе?» → записи 2026-10-26..2026-11-01; «Что у меня сегодня?» → записи 2026-10-19. Проверяется по датам созданных/показанных записей.
- **AC-07** (US-3) Запросы «Что у меня сегодня?», «Какие планы на сегодня?» и «Покажи мои встречи на сегодня» трактуются как одно действие «список за сегодня»: выводятся записи на 2026-10-19 (для третьего — только встречи), результат на экране и в ответе совпадает по составу записей.
- **AC-08** (US-3) «Какие задачи у меня на завтра?» показывает только задачи на 2026-10-20; «Что запланировано на эту неделю?» — все записи 2026-10-19..2026-10-25, отсортированные по дате и времени; «Есть ли у меня встречи сегодня?» отвечает «да»/«нет» и перечисляет встречи.
- **AC-09** (US-3) Если за период записей нет, ассистент отвечает «На <период> ничего не запланировано», список пуст.
- **AC-10** (US-4) Пользователь «Демо» (история CSV). Поиск возвращает не более 5 записей; при равной релевантности — раньше по дате. (а) «Я когда-то ставил задачу по договору, найди ее»: все выданные записи — задачи с «договор» в тексте, среди них обязательно id 2 «Отправить договор Иваном» и id 5 «Проверить техническое задание по договору». (б) «Найди задачу про презентацию»: все выданные — задачи со словом «презентац…» (не напоминания и не встречи: id 38, 105 не выдаются); id 32 «Проверить презентацию по интеграции» и id 66 «Согласовать презентацию с Иваном» находятся среди первых 5 (допускается замена другими равнозначными задачами при другом ранжировании — тогда проверяется только условие «все — задачи про презентацию»). Порядок внутри выдачи не проверяется.
- **AC-11** (US-4) Пользователь «Демо». (а) «Найди задачу про отчёты» (форма слова отличается от текста) выдаёт задачи с «отчёт», обязательно включая id 7 «Подготовить отчёт». (б) «Когда у меня была встреча с Иваном?» выдаёт только встречи прошлого относительно 2026-10-19 и в ответе перечисляет ровно id 309 (2025-04-04 18:00), id 429 (2025-09-27 15:45), id 530 (2026-03-05 15:45); id 804 (2027-03-20, будущая) не выдаётся, задачи («Отправить итоги встречи Иваном», id 94 и др.) не выдаются.
- **AC-12** (US-4) Если ничего не найдено («Найди задачу про космический корабль»), ассистент отвечает, что ничего не найдено, и предлагает уточнить запрос.
- **AC-13** (US-5) Нераспознанная реплика («Как дела на Марсе?») не создаёт запись; ассистент отвечает, что не понял, и приводит 2–3 примера запросов.
- **AC-14** (US-2) Конфликт: при существующей встрече 2026-10-20 15:00 фраза «Добавь встречу с клиентом завтра в 15:00» ничего не сохраняет сразу, ассистент называет конфликтующую встречу и спрашивает «Всё равно поставить?»; «да» — сохраняет, «нет» — не сохраняет. Встреча длится 1 час: «завтра в 15:30» при той же встрече 15:00–16:00 — тоже конфликт; «завтра в 16:00» — конфликта нет, встреча создаётся сразу.
- **AC-15** (US-6) «Отметь задачу купить билеты выполненной» меняет статус на «выполнено» (виден на экране); «Удали задачу купить билеты» не удаляет сразу, а спрашивает «Удалить задачу «купить билеты»?»; ответ «да» — запись удалена, исчезла из списка на экране и из поиска; ответ «нет» — запись осталась в списке с прежним статусом.
- **AC-16** (US-6) Контекст диалога: после создания встречи с дизайнером фраза «А перенеси её на завтра» меняет дату этой записи на 2026-10-20 (время сохраняется) и ассистент подтверждает перенос; в новом диалоге без предшествующей записи та же фраза ничего не меняет, ассистент спрашивает «Какую запись перенести?».
- **AC-17** (US-6) Если под фразу изменения/удаления подходит несколько записей, ассистент перечисляет их (до 5) с номерами и просит выбрать; без выбора ничего не меняется. Пример: у «Анны» задачи «подготовить отчёт для банка» и «подготовить отчёт для клиента»; фраза «Удали задачу про отчёт» → ответ «Нашёл несколько задач: 1. подготовить отчёт для банка; 2. подготовить отчёт для клиента. Какую удалить?»; ответ «2» → вопрос подтверждения по AC-15 для второй задачи; первая остаётся.
- **AC-18** (US-7) Страница содержит кнопку записи голоса, текстовое поле с отправкой, ленту диалога (реплики пользователя и ассистента), список записей и переключатель звука с подписью «Звук: вкл» / «Звук: выкл» (по умолчанию «вкл»). При «вкл» каждый ответ озвучивается и выводится текстом; при «выкл» ответ только текстом и озвучивание не запускается. Состояние переключателя сохраняется после перезагрузки страницы.
- **AC-19** (US-7) Если браузер не поддерживает распознавание речи или микрофон запрещён, кнопка записи неактивна/показывает сообщение «Голосовой ввод недоступен, введите текст», а текстовый ввод работает полностью.
- **AC-20** (US-8) Записи пользователя «Анна» не видны пользователю «Борис» ни в списках, ни в поиске; переключение имени в интерфейсе без пароля показывает данные выбранного пользователя; новое имя создаётся одним действием.
- **AC-21** (US-1) Записи сохраняются между запросами: после перезагрузки страницы и перезапуска сервера (в том числе на развёрнутой версии после «засыпания» хостинга) созданная запись остаётся и находится запросом «Что у меня завтра?».
- **AC-22** (US-4) После первого запуска у пользователя «Демо» 1000 записей из CSV (повторный запуск не создаёт дубликатов); типы по правилу из Data; при выбранном пользователе «Демо» запрос «Что было 26 января 2024?» возвращает ровно записи id 14 «Провести планёрку по договору» (встреча), id 15 «Обновить материалы по интеграции» (задача), id 16 «Провести планёрку по бюджету» (встреча) в порядке времени 11:00, 12:45, 17:30.
- **AC-23** (US-9) Основные сценарии AC-01..AC-08, AC-10 работают без платного API-ключа: без каких-либо ключей в окружении приложение запускается, и фразы из этих критериев дают указанные результаты.
- **AC-24** (US-9) Репозиторий содержит README (запуск, выбор технологий, самостоятельные решения, что улучшить), описание архитектуры с разделением голос / понимание запроса / бизнес-логика / хранение, и ссылку на работающий прототип, открывающийся без входа по паролю. Пока доступа к хостингу нет (см. Risks), достаточно: README с пошаговой инструкцией локального запуска и деплоя, ссылка добавляется после получения доступа.

## Reports
Отдельных отчётов нет. Ответ ассистента — голосом и текстом, плюс список записей на экране (тип, текст, дата-время, статус), по умолчанию ближайшие.

## Integrations
- Распознавание и синтез речи — встроенные возможности браузера (без ключей), русский язык.
- Понимание запросов — бесплатный/локальный подход без платного ключа (правила + нормализация, лёгкий локальный/бесплатный поиск по смыслу). Необязательный LLM-ключ может улучшить понимание, но не требуется.
- Календарь, e-mail, push-уведомления — нет.

## Out of scope
Реальный календарь; повторяющиеся задачи и встречи; пароли/регистрация/роли; push-напоминания в назначенное время; мобильное приложение; платные облачные речевые сервисы; бизнес-часы и часовые пояса помимо Москвы.

## Constraints
- Язык интерфейса и распознавания — русский; часовой пояс Europe/Moscow.
- Бесплатный хостинг, открытая ссылка; работа в современном Chrome/Edge (голос), текст — в любом браузере.
- Технологии не заданы — выбирает команда; без платных ключей и секретов в репозитории.
- Хранилище данных постоянное: переживает перезапуск и «засыпание» хостинга (локальный диск эфемерного хостинга не подходит; нужна управляемая БД или персистентный том) — требование AC-21.
- Разделение слоёв: голос (браузер), понимание запроса, бизнес-логика, хранение.

## Assumptions
- Q13 (технологии) без ответа: предпочтений нет, стек выбирает команда.
- Каждый вопрос интервью, кроме Q13, отвечен; уточнения по ним принятые как допущения ниже.
- Допущение: пользователи различаются только по имени (без пароля, по открытой ссылке); имена не секретны.
- Допущение: CSV принадлежит пользователю «Демо», остальные видят пустую историю; у импортированных записей статус «не выполнено», дата создания — момент импорта.
- Допущение: правила определения типа по CSV — ключевые слова из раздела Data; в тексте CSV встречаются грамматически неточные фразы («Отправить договор Иваном»), они сохраняются как есть.
- Допущение: «до конца недели» = воскресенье текущей недели; «в пятницу» — ближайшая будущая пятница; «в 10 утра» = 10:00; «утром» без часа = 09:00; «вечером» без часа = 19:00; «в 11» без уточнения = 11:00.
- Допущение (ответ на ревью): при поиске с лимитом 5 и множеством равнозначных записей (презентации, отчёты) проверяется свойство выдачи (тип и ключевое слово), а не полный список; раньше по дате при равной релевантности. Правило типов по CSV уточнено (начало текста), чтобы «итоги встречи» были задачами.
- Допущение (ответ на ревью): запрос «была встреча» — прошлое относительно «сейчас»; будущие встречи выдаются запросом «будет/запланирована».
- Допущение: состояние переключателя звука хранится в браузере (localStorage).
- Допущение: задача без времени допустима; встреча без времени требует уточнения (AC-05); встреча без даты тоже.
- Допущение: удаление требует подтверждения; продолжительность встреч для конфликтов — 1 час.
- Допущение: контекст диалога хранится на сервере/в сессии пользователя и ограничен последней упомянутой записью.
- Допущение: фиксация «сейчас» для тестов — технически допустимая конфигурация; в обычной работе берётся реальное время МСК.

## Risks
- Без LLM точность разбора свободной речи ниже: покрываем списком фраз из ТЗ и вариаций; запасной вариант — уточняющий вопрос (AC-13).
- Распознавание речи браузера зависит от браузера/сети (Chrome отправляет звук в сервис Google); запасной вариант — текстовый ввод (AC-19).
- Бесплатный хостинг может «засыпать» и терять локальный диск: пользовательские записи переживают это только с постоянным хранилищем (Constraints, AC-21); повторный импорт CSV восстанавливает лишь «Демо» и не заменяет его. Запасной вариант: бесплатная внешняя БД или персистентный том; если такого нет — AC-21 проверяется локально, а ограничение демо-версии описывается в README. Возможна холодная задержка первого запроса.
- Нет доступа к аккаунту хостинга и git-хостингу (access-checklist): AC-24 (ссылка на репозиторий и работающий прототип) не выполнить сразу. Запасной вариант: запуск локально по README, пошаговое описание деплоя, ссылки добавляются после получения доступа; остальные AC проверяются локально.
- Семантический поиск без платного API: локальная модель может не уместиться в лимиты бесплатного хостинга; запасной вариант — нормализация словоформ и нечёткое соответствие.
- Открытая ссылка без пароля: любой может видеть данные по имени пользователя; не вводить в прототип личные данные (приватность).
