# Access checklist

- [ ] Аккаунт на бесплатном хостинге (если команда выберет вариант, требующий вашего аккаунта) — публикация работающего прототипа (до этого команда готовит запуск локально и инструкцию в README)
- [ ] Ссылка на репозиторий с исходным кодом (git-хостинг, например GitHub) — обязательный результат ТЗ (до этого код лежит в папке проекта)
- [ ] Необязательно: ключ LLM (Anthropic/OpenAI) — улучшение понимания запросов; без него всё работает на бесплатном подходе (ключ в .env, не в репозитории)
