# Glossary

- **Пользователь** — человек, выбранный по имени в переключателе; единственная роль. Свои записи и свой диалог.
- **Запись** — задача, встреча или напоминание пользователя с названием, датой/временем (у задачи может не быть) и статусом.
- **Задача** — тип записи без обязательного срока; также тип по умолчанию, если текст не похож на встречу или напоминание.
- **Встреча** — тип записи: текст начинается с «встреч», «созвон» или «демо», либо содержит «планёрк».
- **Напоминание** — тип записи: текст начинается с «напомн».
- **Статус записи** — «не выполнено» или «выполнено».
- **История диалога** — реплики пользователя и ассистента; нужна для контекста («перенеси её на завтра») и показа на экране.
- **Начальная история** — записи из `voice_assistant_events.csv`, загруженные как готовые данные для поиска; принадлежат пользователю «Демо».
- **Демо** — демо-пользователь с начальной историей.
- **План на период** — список записей пользователя за выбранный период.
- **Уточняющий вопрос** — вопрос ассистента, когда в запросе не хватает данных для записи или поиска.
- **Часовой пояс** — Europe/Moscow (UTC+3) везде в проекте.
- **Намерение (intent)** — результат разбора реплики парсером: что пользователь хочет сделать (создать, показать план, найти, уточнить и т. д.) и с какими данными.
