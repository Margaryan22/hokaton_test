# ADR-003: Состояние диалога — серверный конечный автомат в таблице dialog_states

## Context
AC-05 (уточнение времени), AC-14 (подтверждение конфликта), AC-15 (подтверждение удаления), AC-17 (выбор из нескольких) и AC-16 («перенеси её») требуют помнить между репликами, чего ассистент ждёт и о какой записи шла речь. Бриф (Assumptions): контекст хранится на сервере и ограничен последней упомянутой записью.

## Decision
На пользователя одна строка `dialog_states(user_id PK, state_json, focus_record_id, updated_at)`.
- `focus_record_id` — последняя запись, которую ассистент создал, изменил, отметил или выдал единственным результатом; цель для «её/его/эту». Удаление записи обнуляет его (FK `on delete set null`).
- `state_json` — одно из состояний (Zod-схема `DialogStateSchema` в `src/server/dialog/state.ts`):
  `idle` | `await_slot {draft, missing}` | `await_conflict {write, conflictIds}` | `await_delete {recordId}` | `await_choice {op, candidateIds, change?}` | `await_target {op, change?}`.
- Из состояния выводится `expect` для парсера: `slot` | `yes_no` | `choice` | `target` | `null`. Парсер сначала пробует ожидаемую форму ответа, затем обычную команду.
- Новая полноценная команда в любом ожидающем состоянии отменяет ожидание и выполняется; «отмена/стоп/не надо» — отменяет с ответом «Хорошо, отменил»; непонятный ответ — повтор вопроса.
- Подтверждение применяется только к id, сохранённым на сервере в состоянии, никогда к id из запроса клиента.
- «Новый диалог» (`POST /api/dialog/reset`) удаляет реплики и сбрасывает состояние и фокус.

## Alternatives
- Хранить в cookie/клиенте — подделка цели удаления, рост cookie.
- Восстанавливать контекст разбором истории реплик — хрупко и медленно.
- Память процесса — теряется на serverless между вызовами (AC-21).

## Consequences
- Каждый шаг диалога — чистая функция `transition(state, intent, data) → {state, effects, reply}`, тестируемая без HTTP.
- Состояние валидируется при чтении; повреждённое/устаревшее сбрасывается в `idle`.
- Одна вкладка на пользователя — допущение прототипа; гонки двух вкладок не решаются.
